# 小地球 · Pixel Earth

个人娱乐项目。目标是一个摄像头手势控制、可以自由造景和观察生态的小地球。

## 当前阶段

基础球体 v0.2：只保留陆地、海洋与蓝天，本轮完善光照系统。
用户已确认球体形态；保留克制的自然风格，内容逐层添加。

- 已实现范围：原生 WebGL 球体、程序化陆海分布、可调日照、环境补光、海面反射、轮廓散射、亮度控制、鼠标/触屏/键盘旋转缩放、回到初始视角。
- 后续范围：细像素纹理、地形起伏、河流、植物、生态、摄像头手势、存档。
- 本阶段不表示后续范围已实现。

右上角太阳按钮打开光照面板，可选择晴日、暖阳、侧光，调整日照强度、暗部补光和整体亮度；“太阳位置”展开方向与高度设置。
“恢复默认光照”只复位光照，右上角视角复位按钮只复位观察位置。

## 文件

- `dist/`：可直接托管的网页文件，无第三方运行依赖。
- `docs/DIRECTION.md`：已确认方向、阶段边界与验收状态。
- `.openai/hosting.json`：私有小样的托管配置。

可使用任意静态文件服务器打开 `dist/`。所有渲染与输入在浏览器本机完成。
