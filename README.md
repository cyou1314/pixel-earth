# 小地球 · Pixel Earth

一颗可以旋转、缩放的小地球。v0.5.1 在立方球地形与手势基础上强化三维体积：宽山脊、贴地河流、斜向日光、地形阴影和漂移云影。

[打开网页](https://pixel-earth-foundation-cyou1314.jaycyou.chatgpt.site) · [基础版对照](https://pixel-earth-foundation-cyou1314.jaycyou.chatgpt.site/foundation/)

## 当前阶段：v0.5.1 地形与空间层次

继续使用 Babylon.js 9.30.0。立方体六个面映射为圆润球体；面边界共享地形数据，法线保持连续。陆地约占 48%，具备连续山脊、山谷、沙色海岸、深浅海面与按像素采样衰减的地表细节。山峰最高约为球半径的 12.5%，高地与陡坡自然过渡到岩石色。

地形图上计算优先洪泛排水网络，生成 16 条连到海岸的程序河道；河道按实际地形三角形裁分贴合，减少陡坡穿模。云层位于独立球壳，缓慢漂移，向陆地与海面投射随太阳方向变化的云影；左下角按钮同时隐藏云层与云影。水波、云层在系统要求减少动态效果时静止。

默认晴日采用侧上方日光与较低补光，地形接触阴影保留坡面的明暗差。鼠标拖动、滚轮和双指缩放、键盘、缩放比例与边界反馈、光照预设和五项参数继续保留。横竖屏取景、加载提示、重试和基础版入口沿用上一阶段。

自由放置物件、存档和生态模拟仍是后续阶段。

## 摄像头手势

点击右下角手势按钮后才请求摄像头：

- 张开手掌并移动：旋转地球；握拳暂停。
- 捏合拇指与食指后，手掌前后移动：拉近或推远。
- 识别丢失、手指松开后重建基准，避免重新识别时突然跳动。
- 关闭面板、再次点击手势按钮或切到后台会停止视频流；支持授权拒绝、无摄像头、设备占用和模型失败提示。

识别使用版本锁定的 MediaPipe Hands 轻量模型，JS、模型、图与两种 WebAssembly 构建均在站点本地托管。视频帧只交给本机识别器，不上传、录制或保存。手势与摄像头尚未进行真人和真机验收；页面嵌入窗口的摄像头权限也可能受浏览器限制。

## 使用源码与页面打包

```bash
npm ci
npm run build
npm run check
```

`pixel-earth.html` 是 HTML/CSS 和页面启动入口；`src/v05/` 是地形、排水、材质、交互与手势实现。构建生成本地引擎模块，并按所提供的拆分流程写入 `dist/index.html`、`style.css`、`app.js`、`world.js`、`boot.js` 和 `build.json`。

`npm run import:standalone -- /绝对路径/pixel-earth.html` 支持导入兼容的单文件页面。结构或 JavaScript 语法检查失败时停止写入。当前项目使用本地引擎和手势资产，修改源码后以 `npm run build` 为完整构建入口；仅拆分 HTML 不会重新打包引擎。

`npm run check` 检查导入一致性、真实场景和合成手势输入。可选 Linux 着色器检查：

```bash
python3 scripts/check-shaders.py --v05
```

`dist/` 可用静态服务器托管。首次加载只加载页面、引擎和天空环境；手势运行资产在开启摄像头后按需加载。引擎包和 MediaPipe 运行资产是可复现的构建产物，不提交重复二进制，由锁定依赖生成并随部署归档本地托管。

## 验证与边界

已通过：

- 立方球网格、接缝法线、球面面积与陆海比例检查。
- 实际排水网络无循环、16 条河道到海、河道水面与云层球壳检查。
- 六种横竖屏尺寸的实际相机投影、光照、云层开关、水波参数和复位检查。
- 陆地、海洋、河流、云层、大气及三组 PCF 变体的桌面 EGL 编译与链接。
- 合成手部关键点的旋转、捏合缩放、丢失与重新识别检查。
- 模拟摄像头 API 下的拒绝授权、关闭视频流和等待授权时取消检查。
- 本地模型与 WebAssembly 文件、页面 DOM 绑定、语法和打包一致性检查。

NullEngine 不渲染最终像素，桌面 EGL 不等同浏览器 WebGL；合成关键点与模拟摄像头不等同真人手势验收。当前会话没有可用的浏览器控制工具，未运行替代浏览器。CSS、浏览器最终画面、真人摄像头识别与设备性能仍待实际确认。

本轮结果见 [v0.5.1 立体感升级](docs/V0.5.1.md)、`docs/previews/depth-v0.5.1/`；[v0.5 原始记录](docs/V0.5.md) 保留。旧版 Blender 工程、模型、基础版与检查记录均保留；v0.5 的几何由 JavaScript 生成，不会自动读取对旧 GLB 的修改。
