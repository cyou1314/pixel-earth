# 方向与验收记录

更新日期：2026-10-15（北京时间）

## 当前阶段：v0.3 免费引擎样片

用户要求引入能够辅助制作的免费工具，并授权专用仓库与网页公开。选择 Babylon.js + Blender + Babylon.js Editor 的制作流程，本轮实际使用前两项；提供可导入编辑器的资产，尚未安装或测试用户电脑上的编辑器。

- 使用 Babylon.js 的网格、PBR 材质、HDR 环境、灯光与阴影。
- 实际用 Blender 4.0.2 生成可编辑 .blend 和网页加载的 GLB；陆海分布沿用 v0.2 的同一地形函数，默认相机和球体朝向保留。
- 陆地具有浅起伏，海洋是独立球面；顶点颜色描述材质色彩，光影没有画死在颜色纹理里。
- 使用原创天空 HDR 和水面法线，没有付费素材或第三方运行 CDN。
- 保留原有光照控制、旋转缩放和简洁界面，在光照面板中提供基础版对照。
- .blend 工程、GLB 与导出脚本保留在仓库，编辑导出不会覆盖原工程。

### v0.3 验证

- Blender 实际生成、保存工程和导出 GLB 成功；实际重开工程并完成 Cycles 参考渲染。
- 打包后的 Babylon.js 使用 NullEngine 实际导入 GLB：陆地 13,039 个顶点、25,280 个三角形；海洋 4,751 个顶点、9,024 个三角形。
- 网格位置与法线为有限数，法线归一且朝外；陆地最大半径约 1.0554，海面半径约 1。
- 独立 PBR 材质、水面法线、阴影投射与接收关系、六面 HDR 解码、三种光照预设、太阳方向、缩放边界和复位检查通过。
- JavaScript 语法、静态文件、唯一 DOM ID 和 Git 空白检查通过。
- 未做浏览器 WebGL、实际控件、响应式布局、Babylon.js Editor GUI 或用户设备性能验收。当前环境缺少 Sites 指定浏览器技能；没有使用替代浏览器路径。
- docs/previews/engine-v0.3/blender-reference.png 是 Blender 参考渲染；validation.json 是场景检查记录。两者均不是网页截图。

### 下一项验收

在用户设备对照基础版，先确认光感、陆海材质、海岸起伏和操作流畅度。确认后再推进精细像素纹理或下一层世界内容。

## 已确认

- 用途：个人娱乐。
- 最终主要乐趣：自由造景与生态观察。
- 世界形态：圆形小地球，可以放大缩小，充分利用窗口。
- 最终操作方向：摄像头手势。
- 原视觉方向：圆润自然的立体形状与精细像素纹理。
- 自然为主；少量木屋、木桥和小路是后续内容候选。
- 光影非常重要，界面干净。
- 第一阶段默认午后暖阳。
- 新建专用私有 GitHub 仓库，建议名称 pixel-earth。

## v0.2 反馈与此前方向

用户已确认当前球体符合目标；光影仍不到位，整体暗淡。当前只调整光影并加入光照系统，后续内容继续逐层添加。

用户否定之前的全景：不立体、缺少设计与光感；整体儿童化，缺乏吸引力。
新的推进顺序：从最简单的球体开始，只有陆地、海洋和蓝天，再逐层填充。

## v0.2 阶段边界（历史）

- 真实三维球体。
- 简化、程序化陆海分布；不是现实地球的精确地图。
- 可理解的球面明暗与海面反光。
- v0.2：可调日照、环境补光、海面反射、轮廓散射和亮度映射；默认明亮午后光。
- 光照面板默认收起，提供晴日、暖阳、侧光与五项参数；不加入新的世界物件。
- 鼠标拖动与滚轮缩放；触屏和键盘作为基础输入。
- 界面保留标题、操作提示、缩放与复位。
- 下一阶段内容由本阶段实际反馈决定。

## 基础球体的持续验收标准

1. 不依靠细碎纹理也能读出球体体积。
2. 陆地与海洋随球体一起旋转，光照方向保持统一。
3. 放大缩小保持同一片陆海位置。
4. 操作有边界与稳定处理；页面缩放不干扰视野操作。
5. 常见屏幕尺寸下球体不变形，控制可触达。
6. 用户提供实际画面和手感反馈后，再添加下一层内容。
