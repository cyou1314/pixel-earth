# 方向与验收记录

更新日期：2026-10-14（北京时间）

## 已确认

- 用途：个人娱乐。
- 最终主要乐趣：自由造景与生态观察。
- 世界形态：圆形小地球，可以放大缩小，充分利用窗口。
- 最终操作方向：摄像头手势。
- 原视觉方向：圆润自然的立体形状与精细像素纹理。
- 自然为主；少量木屋、木桥和小路是后续内容候选。
- 光影非常重要，界面干净。
- 第一阶段默认午后暖阳。
- 新建专用私有 GitHub 仓库，建议名称 pixel-earth。

## 最新反馈

用户已确认当前球体符合目标；光影仍不到位，整体暗淡。当前只调整光影并加入光照系统，后续内容继续逐层添加。

用户否定之前的全景：不立体、缺少设计与光感；整体儿童化，缺乏吸引力。
新的推进顺序：从最简单的球体开始，只有陆地、海洋和蓝天，再逐层填充。

## 当前阶段边界

- 真实三维球体。
- 简化、程序化陆海分布；不是现实地球的精确地图。
- 可理解的球面明暗与海面反光。
- v0.2：可调日照、环境补光、海面反射、轮廓散射和亮度映射；默认明亮午后光。
- 光照面板默认收起，提供晴日、暖阳、侧光与五项参数；不加入新的世界物件。
- 鼠标拖动与滚轮缩放；触屏和键盘作为基础输入。
- 界面保留标题、操作提示、缩放与复位。
- 下一阶段内容由本阶段实际反馈决定。

## 本阶段验收

1. 不依靠细碎纹理也能读出球体体积。
2. 陆地与海洋随球体一起旋转，光照方向保持统一。
3. 放大缩小保持同一片陆海位置。
4. 操作有边界与稳定处理；页面缩放不干扰视野操作。
5. 常见屏幕尺寸下球体不变形，控制可触达。
6. 用户提供实际画面和手感反馈后，再添加下一层内容。
