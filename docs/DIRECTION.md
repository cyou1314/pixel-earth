# 方向与验收记录

更新日期：2026-10-15（北京时间）

## 当前阶段：v0.5 像素地形与手势小样

用户要求按所提供脚本中的 v0.5 目标直接更新，而非停留在导入工具。已实现 `pixel-earth.html` 与 `src/v05/`，包含立方球地形、精细像素色彩、16 条程序河流、可关闭薄云、主动开启的本机摄像头手势。

沿用 Babylon.js、光照和视角系统；新增 MediaPipe Hands 的具体用途为本机手部关键点识别，模型和运行时本地托管。没有付费 API 或视频上传。关闭、后台或取消开启会停止摄像头流。

实际场景、接缝、河网、投影、五组桌面 EGL 着色器、合成手部输入与模拟摄像头生命周期检查通过。浏览器 CSS、WebGL 像素、真人识别和设备性能仍待验收。详细结果与风险见 [v0.5 实现与验收](V0.5.md)。

## v0.4 海陆与水面（历史）

反馈：虽然比此前改善，质感仍粗糙、陆地面积偏少、海洋缺乏表现。继续使用免费 Blender + Babylon.js，并实际引入 Poly Haven 的 CC0 天空环境辅助反射。

- 原地形函数测算全局陆地覆盖约 12.2%；新布局在 20,000 个等面积球面方向上测得约 48.1%。不采用真实地球地图。
- Blender 重制分开的陆海网格，增加岸线精度，压低碎片起伏，保留大陆之间的海湾和开阔海域。
- 海洋由深海蓝与浅滩青色、PBR 反射和三维连续细波共同表现；去掉重复 UV 造成的环状水纹。
- 晴日光从右上方落在海湾，界面保持干净；旋转缩放与光照调节保留。
- 普通模式静止时约 30fps 更新水波，隐藏标签页不绘制；系统减少动态效果时水波静止。
- 独立保存 v0.4 `.blend`、GLB、环境 HDR。v0.3 原工程与资产未覆盖。

## v0.3 免费引擎样片（历史）

用户要求引入能够辅助制作的免费工具，并授权专用仓库与网页公开。选择 Babylon.js + Blender + Babylon.js Editor 的制作流程，本轮实际使用前两项；提供可导入编辑器的资产，尚未安装或测试用户电脑上的编辑器。

- 使用 Babylon.js 的网格、PBR 材质、HDR 环境、灯光与阴影。
- 实际用 Blender 4.0.2 生成可编辑 .blend 和网页加载的 GLB；陆海分布沿用 v0.2 的同一地形函数，默认相机和球体朝向保留。
- 陆地具有浅起伏，海洋是独立球面；顶点颜色描述材质色彩，光影没有画死在颜色纹理里。
- 使用原创天空 HDR 和水面法线，没有付费素材或第三方运行 CDN。
- 保留原有光照控制、旋转缩放和简洁界面，在光照面板中提供基础版对照。
- .blend 工程、GLB 与导出脚本保留在仓库，编辑导出不会覆盖原工程。

## 已确认

- 用途：个人娱乐。
- 最终主要乐趣：自由造景与生态观察。
- 世界形态：圆形小地球，可以放大缩小，充分利用窗口。
- 最终操作方向：摄像头手势。
- 原视觉方向：圆润自然的立体形状与精细像素纹理。
- 自然为主；少量木屋、木桥和小路是后续内容候选。
- 光影非常重要，界面干净。
- 第一阶段默认午后暖阳。
- 新建专用私有 GitHub 仓库，建议名称 pixel-earth。

## 基础球体的持续验收标准

1. 不依靠细碎纹理也能读出球体体积。
2. 陆地与海洋随球体一起旋转，光照方向保持统一。
3. 放大缩小保持同一片陆海位置。
4. 操作有边界与稳定处理；页面缩放不干扰视野操作。
5. 常见屏幕尺寸下球体不变形，控制可触达。
6. 用户提供实际画面和手感反馈后，再添加下一层内容。
