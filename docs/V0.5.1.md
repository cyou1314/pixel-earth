# v0.5.1 · 地形体积与空间层次

2026-10-16（北京时间）。基于用户最新 GitHub `2c83f93`，保留之前 10 个性能和交互优化提交。

## 改动

- 地形细分 64 → 80，最高海拔由球半径约 2.9% 增至 12.55%。宽山脊、山谷和低海岸形成可见轮廓，陡坡与高海拔自然转为岩石色；大陆布局保持一致，面积约 47.92%。
- 晴日从侧上方照亮球体，补光 55 → 30，曝光 110 → 105，保留可读暗部。三个预设与五项光照参数仍可调整。
- 阴影由 12px 宽模糊 ESM 改为 WebGL 2 PCF / WebGL 1 Poisson；固定适合整个旋转球体的投影范围。没有增加后处理或第三方依赖。
- 河带按实际地形三角形裁分后投影，解决加高地形后河流切入山坡的问题；保留 16 条河流和渐低、展开的河口。
- 云层位于半径 1.17 的球壳，大气外层约 1.19；云面明暗随日照变化，云影根据太阳方向与同一密度场投到陆海表面。云层漂移和地球旋转共用坐标变换，关云或关闭日照会去除相应云影。云仍为带明暗的薄壳，不是体积光线步进云。
- 明确云层、大气透明绘制顺序，取景按 1.20 外层半径留白。逐帧复用向量、矩阵和四元数，保留用户最新精简依赖、缩放、摄像头断开与握拳优化。
- 修复组合材质的着色器缓存冲突：像素、水波与云影插件各自声明独立特征，避免加入云影后海洋误用陆地程序。

## 验证

- `npm run build`、`npm run check` 通过。检查实际场景几何、连续法线、球面积、河网出口、河面贴合、真实阴影绘制回调、阴影投影范围、六种横竖屏相机投影、云影坐标/开关，以及合成手势、模拟摄像头生命周期与断开事件。
- 河面在顶点、边及三角形中心共 88,066 个采样处均高于实际地形；径向间距约 0.000193–0.001018。此间距只用于避免深度冲突。

## 边界

当前会话没有可用的浏览器控制工具，未通过其他浏览器路径代替。NullEngine 检查不绘制最终像素，桌面 EGL 与 Blender 不能替代浏览器 WebGL、CSS、真实阴影外观和手机性能验收。摄像头真人识别也仍待实测。

增强地形和严格贴地河道增加了三角形数量，云影增加了片元计算；依旧采用本地程序化数据与 1024 阴影贴图，没有增加运行依赖或贴图下载。引擎包约 2.09 MB（未 gzip），保留用户上一轮移除 glTF loader 的体积优化。后续先根据用户浏览器和手机反馈调整细分、阴影及云影开销，再推进物件、生态或存档。
