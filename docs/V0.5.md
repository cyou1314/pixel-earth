# v0.5 实现与验收

2026-10-15（北京时间）。根据用户给出的 v0.5 功能目标，直接补齐页面和运行实现。

## 结果与修改

- `pixel-earth.html` 维护 HTML、CSS 和启动代码；`src/v05/app.js` 打包为本地引擎入口；沿用用户提供的拆分流程生成六个 dist 文件，版本为 0.5.0。
- `terrain.js` 将立方体六个面映射至球面，共享边缘与角点的数据。地表仍连续圆润，颜色采用离散色阶与细小像素变化，远处按采样覆盖范围衰减。
- 实际地表 25,350 个渲染顶点、49,152 个三角形，拓扑唯一节点 24,578；海洋 12,288 个三角形。球面面积估算陆地约 47.95%，最高半径约 1.0289。
- 排水网络使用优先洪泛填洼，保证下游关系无环，并从积水量与源点距离筛选 16 条程序河道。河面独立生成并贴合地形，河口进入海洋。这是静态程序水系，不是实时水文或生态模拟。
- 薄云是独立球壳上的透明程序材质，缓慢漂移，可用按钮关闭；水波和云层遵循减少动态效果设置。
- `HandCamera` 接入实际 MediaPipe Hands 摄像头管线；`GestureInput` 将关键点映射为旋转、捏合缩放与握拳暂停。丢失后清除基准，避免再次识别时跳动。
- 摄像头仅由用户按钮启动；关闭、后台、授权取消和识别错误会清理流。JS、轻量模型、图和 WebAssembly 均为锁定版本的本地资源。

## 已执行验证

1. `npm run build`：页面结构与 JavaScript 语法、Babylon 引擎模块打包、手势资产复制、六文件拆分及版本一致性。
2. `npm run check`：真实 NullEngine 场景中的网格与法线、立方体接缝、陆海面积、河流到海、河网无环、河面与云层半径、光照、水波、云层开关、缩放与复位。
3. 六种实际相机投影：1280×800、1920×1080、800×800、393×852、320×568、844×390；包括最外层大气在内的初始视野完整。
4. `python3 scripts/check-shaders.py --v05`：从实际场景准备的五组着色器提取源码，经明确适配后在 EGL / desktop OpenGL 编译、链接陆地、海洋、河流、云层和大气程序。
5. 合成关键点检查：张掌移动、捏合拉近、跟踪丢失与重新识别不跳动。
6. 模拟摄像头 API 检查：成功开启与关闭、停止视频轨道、关闭识别器、等待授权期间取消、拒绝授权后的状态恢复；模型初始化期间取消并重新开启时，旧初始化先清理，避免并行创建识别器。
7. 本地模型 TFL3 与 WebAssembly 文件头、运行资源、DOM 绑定与唯一 ID；JavaScript / Python 语法和 Git 空白检查。

记录：`docs/previews/world-v0.5/validation.json` 和 `shader-validation.json`。

## 风险与待确认

当前环境缺少 Sites 指定的浏览器控制技能，没有启动替代浏览器或用模拟结果代替真机验收。NullEngine 不渲染像素，桌面 EGL 不等同浏览器 WebGL；合成关键点与模拟 API 也不验证相机、识别准确度或真人手感。

待实际网页确认：CSS 横竖屏、像素纹理远近尺度、河流与云层的最终观感、模型首次加载耗时、浏览器摄像头权限、不同肤色/背景/光线下的真人识别与设备帧率。若嵌入窗口不允许摄像头，可在独立浏览器标签页使用。

`geometry-reference.png` 是导出网格的 Blender 几何检查图，未复刻网页像素着色与薄云；不会作为网页截图使用。可在 `npm run check` 后用 `blender --background --python scripts/render-v05-reference.py` 重现。旧工程、旧模型、基础版和历史验证记录继续保留。
